# Adidas Sales Performance Dashboard

A comprehensive data analytics and visualization project that provides actionable insights into Adidas' retail performance, regional profitability, and product trends.

---

## 📊 Dashboard Overview

<img width="1265" height="419" alt="Screenshot 2026-06-09 125130" src="https://github.com/user-attachments/assets/3068206c-9832-4e13-8c7c-e2fdcfaf3efc" />


The project features an interactive dashboard designed to track key business metrics, identify growth opportunities, and monitor monthly sales health. 

The dashboard is structured into four main analytical views:
* **Total Profitability & Region Tracking:** Breaks down total profits by product categories (**Footwear** leading at **62%**, followed by Apparel and Accessories) and visualizes geographic performance across key Middle Eastern markets (**Egypt**, **Iraq**, **KSA**, **Lebanon**, and **Oman**).
* **Product Performance by Order Volume:** Identifies top-performing merchandise, with classics like *Stan Smith* (76 orders) and *Superstar* (73 orders) leading the volume.
* **Monthly Order Trends:** A time-series line chart highlighting peak performance seasons (reaching a high of **127 orders in May**) and flagging recent sales dips during Q4 to prompt strategic adjustments.
* **Revenue Mapping:** A detailed bar chart breaking down precise financial revenue per product line, led by high-value items like *Predator Freak* ($9,218.42) and *Ultraboost Light* ($8,876.32).

---

## 🚀 Features

* **Product Segmentation:** High-level pie chart analysis separating Footwear, Apparel, and Accessories.
* **Geographic Breakdown:** Profit distribution mapping for Middle Eastern sales hubs.
* **Volume vs. Value Analysis:** Compare which products sell the most in quantity versus which generate the highest revenue.
* **Trend Forecasting:** Seasonal line graphs tracking order variations over a 12-month cycle.
